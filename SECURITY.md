# Security and download policy

Report security issues privately to GoreeCloud through established project channels.

- Do not include real TikTok session cookies, credentials or processing-instance keys in bug reports.
- No TikTok account-password collection or credential injection is implemented.
- Provider URLs must use HTTPS, must not contain userinfo, and must not target local/private IPv4 addresses. This is a basic client-side guard, not a complete defense against DNS rebinding.
- A third-party instance operator can see the URL submitted. Choose only trusted services.
- The application cannot verify media copyright ownership, contractual permissions, or creator download settings. Confirming the warning does not grant such rights.
- Preserve original creator watermark/attribution and do not use this application to bypass DRM, protected accounts or access controls.
- Do not publish a downloader backed by an endpoint without its operator's permission.
- Embedded website availability and usage remain subject to the website's terms.
